# VS Code Text File Comparison Extension

This extension allows users to compare two text files and view the differences in a new tab. It also provides the option to open the original files and the differences in various combinations.

## Features

- Compare two text files and view the differences.
- Open the first and second text files individually.
- Open a new tab displaying the differences.
- Supports various combinations of file views.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd vscode-extension
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Open the project in your code editor.

## Usage

1. Open the Command Palette (Ctrl+Shift+P or Cmd+Shift+P).
2. Type `Compare Files` and select the command.
3. Provide the paths for the two text files you want to compare and the third parameter for additional options.
4. The extension will open new tabs with the original files and the differences.
